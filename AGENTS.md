# Project instructions

## Git workflow

- Work in small, focused Conventional Commits using https://gist.github.com/qoomon/5dfcdf8eec66a051ecd85625518cfd13.
- Use imperative, lowercase descriptions without a trailing period: `type(scope): description`.
- Do not add a `Co-authored-by` line.
- Name branches according to https://conventionalbranch.org/: `<type>/<short-lowercase-description>`.
- Ask the user before accessing or using their accounts or secrets, including remote pushes and deployment credentials.

## Graphify

- When the user types `/graphify`, read the installed Graphify skill at `~/.Codex/skills/graphify/SKILL.md` before doing anything else.
